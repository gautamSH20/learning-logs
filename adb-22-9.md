# Study Notes: ADB (Android Debug Bridge)

## Quick Recall
* **The Core Function:** **ADB** is a command-line tool that lets your computer communicate directly with an Android device or emulator.
* **Architecture:** Operates as a three-part system: a **Client** (your terminal), a **Daemon (adbd)** (background process on the phone), and a **Server** (background manager on your PC).
* **React Native Lifeline:** The `adb reverse` command forms the mandatory network tunnel allowing the device to stream code from your local Metro server.

## Essential CLI Command Matrix

| CLI Command | Primary Function | React Native Developer Use Case |
| :--- | :--- | :--- |
| `adb devices` | Lists all active connected hardware serials. | Verifying the phone's physical USB debugging connection is live. |
| `adb reverse tcp:8081 tcp:8081` | Binds device port 8081 back to the computer's localhost. | **Mandatory.** Allows the phone to fetch the active Metro bundle. |
| `adb shell input keyevent 82` | Simulates pressing the physical menu hardware key. | Instantly opens the overlay **React Native Dev Menu** on-screen. |
| `adb logcat *:E` | Streams live device logs filtered strictly to Errors. | Tracking down native Android app crashes or system exceptions. |
| `adb shell pm clear <pkg>` | Wipes all storage, caches, and databases for an app. | Resetting the application state to simulate a clean "first install". |
| `adb shell input text "str"` | Inputs a text macro array directly into an active target field. | Typing out long, complex API keys or passwords into the emulator. |
| `adb kill-server` | Terminates the background routing engine daemon. | Hard-resetting the connection loop when the CLI hangs or freezes. |

## Gotchas / Common Mistakes
* **The "Device Unauthorized" Loop:** If `adb devices` prints `unauthorized`, you forgot to unlock your phone screen and check the box to allow the computer's RSA key fingerprint debugging signature.
* **Stale Reverse Tunnels:** If you unplug your phone and plug it back in, the `adb reverse` network link drops. You must re-run the command every single time you reconnect the cable, or your app will show a red connection error screen.
* **Multiple Devices Conflict:** If you have an emulator running while a physical phone is plugged in, running standard commands will throw a `more than one device/emulator` error loop. You must target a specific instance using the system identifier flag (e.g., `adb -d <command>` for the hardware device or `adb -e <command>` for the emulator).
